# 嵌入单元材料参数计算器使用说明

`embedded_material_calculator.py` 用于把打印路径几何参数(线宽 w、层高 t)与实测的 3D 打印 CFRC 整体力学性能(论文表 3.1)换算为 `abaqus_cfrc_compare.py` 嵌入单元模型所需的材料参数(各向同性 host 实体 + 嵌入 B31 梁)。

## 原理

Abaqus 的 embedded element 约束是刚度**叠加**式的:梁所在位置的 host 刚度不会被扣除。因此沿纤维方向,对一条打印道次所代表的材料横截面(单元胞截面 A_cell = w × t),标定方程为:

```
E11_实测 × A_cell = E_host × A_cell + E_beam × A_beam
E_beam = (E11_实测 − E_host) × A_cell / A_beam
```

host 必须独立复现实测表中由基体和界面主导的部分(E22/E33 与三个剪切模量),因为梁对横向和剪切没有贡献。所以取 HOST_E = E22、HOST_NU = ν23,脚本会自检各向同性隐含的剪切模量 G = E/(2(1+ν)) 是否落在实测 G12/G13/G23 区间内。注意:这里的"host 基体"不是真实树脂的手册值,而是"扣除纤维轴向贡献后的等效介质",实测 E22 里已经天然包含了打印孔隙与道间界面柔度。

## 快速使用

在仓库根目录运行(Python 2.7、Python 3 以及 `abaqus python` 均可):

```
python embedded_material_calculator.py -w 0.8 -t 0.25
```

输出末尾会给出可直接粘贴进 `abaqus_cfrc_compare.py` 中 `class Config` 的参数块。对当前打印参数(w = 0.8 mm,t = 0.25 mm,梁截面保持 0.6 × 0.15 mm 椭圆)的结果为:

```
HOST_E = 2012.9
HOST_NU = 0.39
BEAM_E_RATIO = 56.714      # 即 E_beam = 114159.5 MPa
```

自检结果:重构 E11 = 42360.2 MPa(与实测完全一致);host 隐含剪切模量 724.1 MPa,位于实测区间 658.1~758.4 MPa 之内;反演纤维体积分数约 17.7%(以 Ef = 230 GPa 计),量级合理。

## 命令行参数

必填参数为 `-w/--width`(线宽,mm)与 `-t/--height`(层高,mm)。表 3.1 的九个常数(`--e11`、`--e22`、`--e33`、`--g12`、`--g13`、`--g23`、`--nu12`、`--nu13`、`--nu23`)均已内置为默认值,表格更新时可在命令行覆盖。`--beam-major` 与 `--beam-minor` 用于修改梁椭圆截面的全轴长(默认 0.6 与 0.15,与仓库当前 Config 一致)。`--host-avg` 会用 (E22+E33)/2 代替 E22 作为 HOST_E;`--host-e` 和 `--host-nu` 可强制覆盖 host 参数(例如想牺牲剪切匹配去逼近 ν12 = 0.29 时)。`--ef` 为纤维本征模量,仅用于 Vf 估算与 fiber 约定。

`--convention` 选择梁的等效约定,三者只要 E_beam × A_beam 相同,轴向刚度完全等价,区别仅在梁自身弯曲惯量:

其一,`ellipse`(默认):沿用仓库现有椭圆截面,只需改 Config 三个数,不动任何代码。其二,`cell`:梁截面取整个单元胞 w × t 矩形,此时 E_beam = E11 − E_host,最直观,但需要把 `setup_beam_material_profile_section` 中 GeneralizedProfile 的 area/i11/i22/j 改为脚本打印的矩形值。其三,`fiber`:梁只代表纯纤维,截面积 = Vf × A_cell,E_beam 约等于纤维本征模量,同样需要改 profile。

## 注意事项

第一,A_cell 必须与**实际导入 FEA 的梁路径间距**一致:面内间距 = 路径生成时的 LINE_WIDTH,层间距 = 导出层的层厚。如果 FEA 路径是用别的线宽生成的(例如旧的 0.4 mm 默认值),要么重新生成路径,要么用那个值重跑本计算器,否则梁密度与标定不符,轴向刚度会成比例偏差。

第二,已知且可接受的失配:模型等效 ν12 ≈ ν_host = 0.39(实测 0.29),各向同性 host 抹平了 E22/E33 与三个 G 之间 ±8% 的差异;embedded 约束等价于完美粘结。这些对整体刚度对比影响为次级。

第三,HOST_DENSITY 未改动。静刚度分析不受影响;若做模态或重力分析,梁体积内存在质量双计,需从梁密度中扣除 host 已占部分。

第四,建议做一次单向标定试件闭环验证:建一个小长方体 host,按 0.8 mm 间距、0.25 mm 层距铺满平行直梁,施加三个方向单轴位移与面内剪切,提取等效模量与表 3.1 对比。E11 应在 2% 以内,E22 与 G 在 10% 以内。此结果可直接用作论文 FEA 方法的 validation 小节。
